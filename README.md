# ZeroSol Sales Partner Platform（デモ）

販売店がメーカーへ案件を持ち込む窓口のプロトタイプ。架空の企業・商材単価を使用しています。

## 起動

Node.js 22以上（検証済み: 24.19.0）。外部パッケージ・APIキー・DBは不要。

```sh
cd /workspace/ZeroSol-home
npm run dev
```

ポート3000で起動。別ポートは `PORT=3001 npm run dev`。検証は `npm test`。

## 試す流れ

1. 「新規案件を登録」で困りごとを入力。推奨商材の候補を表示。
2. 案件詳細から現場調査を保存。写真は一時プレビューのみ。
3. 概算見積を計算し、印刷から提案用PDFを保存。HVLSは個別見積相談へ。
4. 技術相談を記録し、案件の進捗を更新。
5. 右上でZeroSolビューに切り替え、共有許可がない顧客名は非公開になることを確認。

## 制限

データはブラウザのlocalStorageに保存。認証、実際の権限制御、メーカー送信、正式見積発行、ファイル保存は未実装。役割切替は表示デモでありセキュリティ境界ではありません。実顧客情報・機密情報は入力しないでください。ブラウザのサイトデータ削除で初期化できます。メーカーからの直接営業の可否は本実装時に契約とアクセス制御で定義する必要があります。

本番化では認証・販売店単位のデータ分離・監査ログ・共有同意・サーバー保存・承認済み単価と正式見積の承認フローが必要です。

## Netlifyで公開

- 手動公開：`public` 内のファイルをルートに含むZIPをNetlify Dropにアップロードします。ビルドは不要です。
- Git連携：このリポジトリをNetlifyに接続します。`netlify.toml` により公開ディレクトリは `public`。ビルドコマンド・環境変数は不要です。
- 公開版もブラウザ内保存のデモです。メーカー送信・認証はありません。公開後のURLでも実顧客情報を入力しないでください。
